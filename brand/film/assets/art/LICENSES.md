# Art

The robot sprites in `robots/` are from Kenney's Robot Pack (side view PNGs), copied unmodified under Creative Commons Zero (CC0, http://creativecommons.org/publicdomain/zero/1.0/).

- Pack: Robot pack, by Kenney Vleugels for Kenney (www.kenney.nl)
- Pack URL: https://opengameart.org/content/robot-pack (also https://kenney.nl/assets/robot-pack)
- Downloaded from: https://opengameart.org/sites/default/files/Robot%20pack.zip
- License file in the pack (`License.txt`): "License (Creative Commons Zero, CC0)". The OpenGameArt listing also shows CC0.

| Files                                      | Use                                                  |
| ------------------------------------------ | ---------------------------------------------------- |
| `robot_{blue,green,yellow,red}Body.png`    | Standing robot                                       |
| `robot_{blue,green,yellow,red}Damage1.png` | Scratched, frustrated robot while the computer hangs |
| `robot_{blue,green,yellow,red}Jump.png`    | Robot hopping when something lands                   |
| `tracks_short1.png`                        | The robots' tracks                                   |

The sweat drops, steam, hearts, brows and everything else drawn on the robots are original to this film.
