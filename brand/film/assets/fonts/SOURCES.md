# Fonts

The brand has no typeface of its own (the Sky wordmark is drawn paths), so the film uses two free fonts embedded into the player.

| File                                                                      | Font                                 | License                                                  | Source                                                   |
| ------------------------------------------------------------------------- | ------------------------------------ | -------------------------------------------------------- | -------------------------------------------------------- |
| `Inter-var-latin.woff2`                                                   | Inter, variable weight, Latin subset | SIL Open Font License 1.1 (`OFL-Inter.txt`)              | https://github.com/rsms/inter, as served by Google Fonts |
| `DejaVuSansMono-Regular-subset.woff2`, `DejaVuSansMono-Bold-subset.woff2` | DejaVu Sans Mono, ASCII subset       | Bitstream Vera and DejaVu license (`LICENSE-DejaVu.txt`) | the Debian `fonts-dejavu-core` package                   |
